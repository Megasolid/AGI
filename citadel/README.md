# Citadel repository records

This directory contains project coordination and evidence records associated with the public AGI GitHub repository.

- `tasks/` — task-envelope records and their schemas
- `reports/` — reports and evidence submitted for review
- `inputs/` — source inputs, manifests and supporting evidence
- `governance/` — current repository governance documents

Task and report files are records; their presence does not itself authorize execution, publication, identity changes,
federation or deployment. Repository changes are proposed through branches and pull requests. The project owner retains
final authority over protected and consequential decisions.

Older task IDs, agent names and station-specific handoff instructions are historical context, not a current role registry.
Do not treat DSH or Kilo as official AGI roles or stations.
