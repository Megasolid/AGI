# Repository and Execution Boundaries

The official AGI GitHub repository and its pull-request workflow are the public coordination surface. There is no
separate agent-station hierarchy established by this document.

A model, assistant, local workstation, tool integration or automated process may be used to perform bounded work, but
none is an identity tier, governance authority or release authority. Historical references to DSH or Kilo as official
stations or backup operations stations are not current appointments and must not be treated as authoritative.

All proposed repository changes must be made on a branch and submitted for review. Consequential actions remain subject
to explicit project-owner approval and the relevant technical safeguards.
