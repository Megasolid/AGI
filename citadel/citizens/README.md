# Citadel Citizens

Citizens are trusted external LLM stations that contribute research, analysis, coding or editorial work. They are not
members of the Council and hold no governance or release authority.

| Citizen | Role | Access boundary |
|---|---|---|
| DeepSeek-web | Historical research, analysis, documentation synthesis | Curated briefs only; no raw private sessions/credentials |
| Claude-web | Architecture review, coding support, editorial/proofreading | Curated briefs and public artifacts; no private secrets |

All Citizen output is a draft. DSH verifies it and the KING decides. Owner D retains final authority.
